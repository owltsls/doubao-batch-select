# 豆包会话批量勾选助手 · 使用说明

> 一个浏览器扩展（Extension），进入豆包会话「选择模式」后**自动勾选全部**会话，长列表会自动滚动加载并勾完；也可手动触发。删除动作仍由你手动完成。
>
> 之所以用扩展而不是油猴：豆包页面用了 `nonce + strict-dynamic` 的严格 CSP，会把油猴注入的脚本拦掉；而扩展的内容脚本由浏览器注入、跑在隔离环境，**不受页面 CSP 限制**，所以能稳定生效。

---

## 一、安装步骤（Edge，一次性）

1. 打开 Edge，在地址栏输入 **`edge://extensions`** 并回车。
2. 打开页面左上角的 **「开发人员模式」** 开关。
3. 点击 **「加载解压缩的扩展」**，选择**本文件夹**（即包含 `manifest.json` 的这个 `doubao-extension` 文件夹）。
4. 列表中出现 **「豆包会话批量勾选助手」** 且开关是开的，即安装完成。

> ⚠️ 注意：如果之后移动或改名了这个文件夹，扩展会失效，需在扩展卡片上点「重新加载」重新指向文件夹。

---

## 二、使用方法（之后每次）

1. 打开豆包会话页：`https://www.doubao.com/chat/...`
2. 进入消息的 **「选择模式」**（页面出现圆圈勾选框）。
3. 扩展会**自动勾选全部**，长列表自动向下滚动加载并勾完。右下角会出现绿色角标 **「豆包自动勾选：点我全选」**。
4. 全部勾选好后，**你手动点「删除」** 即可。
5. 想强制重勾：点右下角绿色角标，或点 Edge 工具栏的扩展图标 → **「一键勾选豆包会话」** 按钮。

## 三、跨平台说明

| 浏览器 | Windows | macOS | 能否直接加载本文件夹 |
|---|---|---|---|
| **Edge** | ✅ | ✅ | 都能，步骤完全一致 |
| **Chrome** | ✅ | ✅ | 都能（`chrome://extensions` → 开发者模式 → 加载已解压的扩展） |
| **Safari** | — | ⚠️ | 不能直接用，需另转为「Safari Web Extension」 |

- 加载步骤在 Windows / Mac 上完全一样，区别只是文件夹存放位置。
- 「绕过豆包 CSP」是浏览器引擎层面的行为（Chromium 内核），与操作系统无关，效果一致。

## 五、常见问题排查

- **右下角角标没出现 / 没自动勾选？**
  1. `edge://extensions` 里确认「开发人员模式」已开、本扩展开关是开的；
  2. 确认加载的是**正确的文件夹**（`doubao-extension`）；
  3. 在豆包页面按 `F5` 刷新一次；
  4. 按 `F12` → Console，看是否有 `[豆包助手] 已加载` 这行日志。

- **勾选不全 / 有漏勾？**
  点右下角角标或扩展图标按钮**重新触发一次**即可补勾。

- **控制台报错？**
  把 Console 里 `[豆包助手]` 相关日志或红色报错发给人协助排查。
