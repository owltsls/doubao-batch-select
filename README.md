# 豆包会话批量勾选助手

浏览器扩展（Edge / Chrome 通用）。进入豆包会话「选择模式」后，**自动勾选全部会话**；长列表会自动向下滚动加载并勾完。删除动作仍由你手动完成。

## 功能特性

- 进入豆包会话「选择模式」后自动勾选所有圆圈勾选框
- 长会话列表自动滚动加载、边加载边勾选，不漏项
- 右下角绿色角标，点一下即可手动全选
- 扩展图标弹窗「一键勾选」按钮，随时手动触发
- 仅在本地运行，不上传任何数据

## 为什么是扩展，不是油猴脚本

豆包网页端使用了 `nonce + strict-dynamic` 的严格 CSP（内容安全策略），会**拦截**油猴等以页面脚本方式注入的代码，导致脚本无法运行。

浏览器扩展的内容脚本由浏览器扩展机制注入、运行在隔离环境，**不受页面 CSP 限制**，因此能稳定生效。本项目即以扩展形式提供。（早期尝试的 Tampermonkey 脚本因同样原因在该站点失效，故不再提供。）

## 安装（一次性）

### Edge

1. 打开 Edge，地址栏输入 `edge://extensions` 回车。
2. 打开左上角「开发人员模式」开关。
3. 点击「加载解压缩的扩展」，选择本仓库的 `doubao-extension` 文件夹。
4. 列表中出现「豆包会话批量勾选助手」且开关开启，即安装完成。

> 注意：移动或重命名 `doubao-extension` 文件夹后扩展会失效，需在卡片上点「重新加载」重新指向。

### Chrome

步骤相同，地址栏改为 `chrome://extensions`。

图文版安装 / 使用说明见 [`doubao-extension/使用说明-图文版.html`](doubao-extension/使用说明-图文版.html)（双击在浏览器打开）。

## 使用（每次）

1. 打开豆包会话页：`https://www.doubao.com/chat/...`
2. 进入消息「选择模式」（页面出现圆圈勾选框）。
3. 扩展自动勾选全部；右下角出现绿色角标「豆包自动勾选：点我全选」。
4. 全部勾选好后，**手动点「删除」**。
5. 若有漏勾：点右下角角标或扩展图标按钮重新触发。

## 备选方案：控制台版（无需安装扩展）

如果你不想安装扩展，仓库根目录的 [`doubao-console-check.js`](doubao-console-check.js) 提供**控制台方案**：在豆包会话「选择模式」下，按 `F12` 打开 Console，把该文件内容粘贴执行即可（同样不受 CSP 限制）。适合临时一次性使用。
